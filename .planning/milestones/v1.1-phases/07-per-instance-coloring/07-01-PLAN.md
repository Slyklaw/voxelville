<task type="auto">
  <name>Task 1: Rework BuildingRenderer for per-instance coloring</name>
  <files>src/engine/building-renderer.ts</files>
  <action>
    Rework BuildingRenderer to render multi-voxel building models with correct per-voxel colors.

    **Current bug:** `initPools()` creates one InstancedPool per model using only `model.voxels[0].color` as the material. All voxels in a building render the same color. `addBuilding()` adds ONE instance at the building position — only the first voxel renders.

    **The fix:**

    1. Create ONE pool per model using a NEUTRAL white material (getMaterial with a 'white' entry, or create inline `new THREE.MeshLambertMaterial({ color: 0xffffff, flatShading: true })`)

    2. `initPools()` should create pools with size = total voxels across all instances (estimate: model.voxels.length * maxInstances). Use `model.voxels.length` as the per-instance voxel count.

    3. Rework `addBuilding()` to:
       - Accept modelId and position
       - Get the model from ALL_BUILDING_MODELS
       - For each voxel in model.voxels:
         - Calculate world position: `basePos + voxel offset (x, y, z)`
         - Add an instance at that position
         - Call `pool.meshInstance.setColorAt(instanceIndex, color)`
       - Return the first instance index (for compatibility)

    4. Add a helper method or inline logic to convert material name to THREE.Color for setColorAt():
       ```typescript
       const material = getMaterial(voxel.color);
       const color = material ? new THREE.Color(material.color) : new THREE.Color(0xffffff);
       pool.meshInstance.setColorAt(instanceIndex, color);
       ```

    5. The `updateBuilding()` method may need updating if it's used for animation — check current callers.

    **Important:** The pool must have enough capacity for ALL voxels across all instances. If a model has 30 voxels and we support 10 buildings, pool size = 300.

    **Keep:** dispose(), clear(), getPool(), getMeshes() methods unchanged.
  </action>

    - Houses show red walls, blue roofs, dark windows, brown doors (not all same color)

    - Park shows green grass, brown trunk, green leaves, colored flowers
  </verify>
  <done>

  </done>

<task type="auto">
  <name>Task 2: Rework CharacterRenderer for per-instance coloring</name>
  <files>src/engine/character-renderer.ts</files>
  <action>
    Rework CharacterRenderer to render multi-voxel character models with correct per-voxel colors.

    **Current bug:** Same as BuildingRenderer — creates one pool per character model using only `model.voxels[0].color`. Characters have 12 voxels (adults) or 9 voxels (children) with distinct hair/skin/clothing colors, but only one color renders.

    **The fix (same pattern as BuildingRenderer):**

    1. Create ONE pool per model using a NEUTRAL white material:
       ```typescript
       const neutralMaterial = new THREE.MeshLambertMaterial({ color: 0xffffff, flatShading: true });
       ```

    2. `initPools()` creates pools with capacity = `model.voxels.length * 50` (50 chars per model variant max).

    3. Rework `addCharacter()` to:
       - Accept modelId and position
       - Get the model from ALL_CHARACTER_MODELS
       - For each voxel in model.voxels:
         - Calculate world position: `basePos + voxel offset (x, y, z)`
         - Add an instance via `pool.addInstance(worldPos)`
         - Call `pool.meshInstance.setColorAt(instanceIndex, color)` where color comes from `getMaterial(voxel.color).color`
       - Return the first instance index

    4. Rework `updateCharacterInstance()` to update ALL voxel instances for a character:
       - Instead of updating just instance `index`, update instances `index` through `index + model.voxels.length - 1`
       - Each voxel offset (from model.voxels) should be applied to the character's interpolated position
       - Apply animation offset (Y-bob from getAnimationOffset) to all voxel positions

    5. Update `updateCharacter()` and `updateCharacterWithRotation()` similarly if they're used.

    **Helper for color conversion:**
    ```typescript
    function materialToColor(colorName: string): THREE.Color {
      const material = getMaterial(colorName);
      return material ? new THREE.Color(material.color) : new THREE.Color(0xffffff);
    }
    ```

    **Character positioning with voxel offsets:**
    Character voxel coordinates are relative (x, y, z). When placing at world position (wx, wy, wz):
    - World position of voxel = `(wx + vx, wy + vy, wz + vz)`
    - Apply animation Y-bob offset to the base position before adding voxel offsets
  </action>

    - Multiple characters of same type show color variations
