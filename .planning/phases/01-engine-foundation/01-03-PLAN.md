<task type="auto">
  <name>Task 1: Implement OrbitCamera class with mouse controls</name>
  <files>src/engine/camera.ts</files>
  <action>
    Create src/engine/camera.ts:

    OrbitCamera class:
    - Constructor takes camera: THREE.PerspectiveCamera, domElement: HTMLElement
    - Internal state:
      - spherical: { radius: number, theta: number (horizontal angle), phi: number (vertical angle from top) }
      - target: THREE.Vector3 (orbit center, default world center)
      - isDragging: boolean
      - lastMouse: { x, y }

    - initOrbitCamera(camera, domElement) → OrbitCamera instance
    - init() method:
      - Set initial spherical: radius=25, theta=PI/4, phi=PI/3 (45° elevation, 45° horizontal)
      - Set initial camera position from spherical
      - Attach event listeners: mousedown, mousemove, mouseup, wheel
      - mousedown: set isDragging=true, record lastMouse
      - mousemove: if isDragging, compute delta, update spherical.theta and spherical.phi, clamp phi to [0.1, PI/2-0.1] (prevent flip), call update()
      - mouseup: set isDragging=false
      - wheel: adjust spherical.radius with delta (zoom), clamp to [5, 50], call update()

    - update() method:
      - Convert spherical to Cartesian: 
        x = target.x + radius * sin(phi) * cos(theta)
        y = target.y + radius * cos(phi)
        z = target.z + radius * sin(phi) * sin(theta)
      - camera.position.set(x, y, z)
      - camera.lookAt(target)

    - dispose() method:
      - Remove event listeners

    Export: OrbitCamera, initOrbitCamera
  </action>
  <verify>
    OrbitCamera instance created successfully
    Mouse drag changes spherical.theta and spherical.phi
    Camera position updates correctly from spherical coordinates
    Zoom (wheel) changes radius within clamped bounds
    phi clamped to prevent camera flipping
  </verify>
  <done>OrbitCamera class with drag-to-orbit and scroll-to-zoom, proper angle clamping</done>
</task>
