  <name>Task 1: Create OutlineRenderer for back-face outline pass</name>
  <files>src/engine/outline-renderer.ts</files>
  <action>
    Create a new `OutlineRenderer` class that wraps an InstancedMesh and renders black outlines using the back-face technique.

    **The technique:**
    1. Clone the InstancedMesh with a black `MeshBasicMaterial` using `side: THREE.BackSide`
    2. Scale the clone slightly larger (e.g., 1.08) so back faces peek out around edges
    3. Render the outline clone FIRST, then the original mesh normally

    **File:** `src/engine/outline-renderer.ts`

    **Implementation:**

    ```typescript
    import * as THREE from 'three';

    export class OutlineRenderer {
      private outlineMesh: THREE.InstancedMesh;

      constructor(sourceMesh: THREE.InstancedMesh) {
        const outlineMaterial = new THREE.MeshBasicMaterial({
          color: 0x000000,
          side: THREE.BackSide,
        });

        this.outlineMesh = new THREE.InstancedMesh(
          sourceMesh.geometry,
          outlineMaterial,
          sourceMesh.instanceMatrix.array.length / 16  // max instances
        );
        this.outlineMesh.instanceMatrix.setUsage(THREE.DynamicDrawUsage);
      }

      /**
       * Copy instance matrices from source mesh and scale for outline effect.
       * Must be called each frame before renderOutline().
       * @param sourceMesh - The InstancedMesh to generate outlines for
       */
      update(sourceMesh: THREE.InstancedMesh): void {
        const dummy = new THREE.Object3D();

        for (let i = 0; i < sourceMesh.count; i++) {
          sourceMesh.getMatrixAt(i, dummy.matrix);
          dummy.matrix.decompose(dummy.position, dummy.quaternion, dummy.scale);

          // Scale up 8% for outline border
          dummy.scale.multiplyScalar(1.08);
          dummy.updateMatrix();
          this.outlineMesh.setMatrixAt(i, dummy.matrix);
        }

        this.outlineMesh.count = sourceMesh.count;
        this.outlineMesh.instanceMatrix.needsUpdate = true;
      }

      /**
       * Render the outline pass. Call BEFORE rendering the source mesh.
       */
      render(renderer: THREE.WebGLRenderer, scene: THREE.Scene, camera: THREE.Camera): void {
        scene.add(this.outlineMesh);
        renderer.render(scene, camera);
        scene.remove(this.outlineMesh);
      }

      dispose(): void {
        this.outlineMesh.material.dispose();
        this.outlineMesh.dispose();
      }
    }
    ```

    **Key details:**
    - `side: THREE.BackSide` — renders only back-facing triangles (expanded outward by scale)
    - Scale 1.08 — creates ~0.04 voxel border on each side (visible but not overwhelming)
    - `update()` copies matrices from source each frame since instance counts may change
    - Outline mesh is added/removed from scene each frame to avoid interfering with depth
    - Uses `MeshBasicMaterial` — unaffected by lighting, always pure black

<action>
    Integrate OutlineRenderer into the render pipeline so all voxel meshes get cartoon outlines.

    **Part A: Update renderer.ts**

    Add an `OutlineRenderer` manager to the renderer module. Create a `renderWithOutlines()` function that:
    1. Takes an array of mesh+outline pairs
    2. For each pair: calls `outlineRenderer.update(mesh)`, then `outlineRenderer.render()` to draw outlines
    3. Then calls the normal `render()` to draw the main meshes on top

    Keep the existing `render()` function unchanged for backward compatibility.

    **Add to renderer.ts:**

    ```typescript
    import { OutlineRenderer } from './outline-renderer';

    // Type for mesh-outline pairs
    export interface MeshWithOutline {
      mesh: THREE.InstancedMesh;
      outline: OutlineRenderer;
    }

    /**
     * Create an OutlineRenderer for an InstancedMesh.
     * Returns a MeshWithOutline pair for use in renderWithOutlines().
     */
    export function createOutlineFor(mesh: THREE.InstancedMesh): MeshWithOutline {
      return {
        mesh,
        outline: new OutlineRenderer(mesh),
      };
    }

    /**
     * Two-pass render: outlines first, then main meshes.
     * @param ctx - Renderer context
     * @param pairs - Array of mesh+outline pairs to render
     * @param updateCamera - Optional camera update callback
     */
    export function renderWithOutlines(
      ctx: RendererContext,
      pairs: MeshWithOutline[],
      updateCamera?: () => void,
    ): void {
      if (updateCamera) updateCamera();

      // Pass 1: Render outlines (black back-face silhouette)
      for (const pair of pairs) {
        pair.outline.update(pair.mesh);
        pair.outline.render(ctx.renderer, ctx.scene, ctx.camera);
      }

      // Pass 2: Render main meshes on top
      ctx.renderer.render(ctx.scene, ctx.camera);
    }
    ```

    **Part B: Update main.tsx**

    In the `App` component's `useEffect`, after creating all InstancedPool meshes:

    1. Import `createOutlineFor` and `MeshWithOutline` from renderer.ts
    2. Create an array `outlinePairs: MeshWithOutline[]`
    3. For each pool mesh (terrain pools + building meshes + character meshes), call `createOutlineFor(mesh)` and push to array
    4. In the animation loop, call `renderWithOutlines(ctx, outlinePairs)` instead of `render(ctx)`
    5. In cleanup, call `pair.outline.dispose()` for each pair

    **Specific changes in main.tsx:**

    ```typescript
    // After creating all pools and renderers:
    import { createOutlineFor, MeshWithOutline } from './engine/renderer';

    // After terrain pools are added to scene:
    const outlinePairs: MeshWithOutline[] = [];
    for (const pool of pools.values()) {
      outlinePairs.push(createOutlineFor(pool.meshInstance));
    }

    // After building renderer and character renderer are created:
    for (const mesh of buildingRenderer.getMeshes()) {
      outlinePairs.push(createOutlineFor(mesh));
    }
    for (const mesh of charRenderer.getMeshes()) {
      outlinePairs.push(createOutlineFor(mesh));
    }

    // In animation loop:
    function animate(): void {
      if (!running) return;
      requestAnimationFrame(animate);
      // ... existing character update logic ...

      renderWithOutlines(ctx, outlinePairs);
    }

    // In cleanup:
    for (const pair of outlinePairs) {
      pair.outline.dispose();
    }
    ```

    **Why add/remove outline mesh from scene each frame:**
    Adding and removing the outline mesh from the scene ensures:
    - Outline mesh doesn't interfere with the main render pass (depth buffer)
    - Only outlines render during the outline pass, only main meshes during normal pass
    - Simple approach with no custom render target or material tricks needed
