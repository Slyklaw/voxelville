## Objective

Define all building model structures and create a BuildingRenderer to render them in the scene.

**Purpose:** Establish the visual representation of buildings so they can be seen in the voxel world.
**Output:** Building model definitions and a working renderer that displays buildings on screen.

## Context

@src/engine/character-renderer.ts
@src/models/characters.ts
@src/engine/materials.ts

Follow the exact same pattern as CharacterRenderer: per-model-type InstancedPool.
