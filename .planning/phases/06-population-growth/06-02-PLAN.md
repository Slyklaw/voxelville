<task type="auto">
  <name>Task 1: Implement Building Demand Detection and Selection Logic</name>
  <files>src/simulation/growth-system.ts</files>
  <action>
    Add construction demand detection and building selection to growth-system.ts:
    
    1. Define CONSTRUCTION_CONFIG constants:
       - constructionInterval: 240 (ticks, 60 seconds)
    
    2. Implement computeBuildingDemand function:
       - Parameters: population: number, buildings: Building[], buildPriority: typeof uiState.buildPriority
       - Calculate housing demand: residents - totalHouseCapacity
       - Calculate workplace demand: residents - totalWorkplaceCapacity  
       - Calculate leisure demand: residents / (parks + partyHalls) ratio
       - Return sorted list of demand objects by urgency * priority
    
    3. Implement selectBuildingToConstruct function:
       - Use demand list from computeBuildingDemand
       - Apply slider-weighted priorities from uiState.buildPriority
       - Office/store priorities: 0.7 + (0.6 * sliderValue)
       - Park/partyhall priorities: 0.7 + (0.6 * (1 - sliderValue))
       - Return building type with highest urgency * priority
    
    4. Implement findBuildingPlacement function:
       - Get all road tiles from roadGrid.getAllTiles()
       - Shuffle roads using rng for randomness
       - For each road, check adjacent cells (N/S/E/W) using canPlaceBuilding()
       - Return first valid placement coordinate
    
    5. Implement autoConstructBuilding function:
       - Parameters: buildingType, roadGrid, buildingRenderer, rng
       - Call findBuildingPlacement to get coordinates
       - If valid placement found, call placeBuilding() to place the building
       - Add new building to buildings array with capacity/occupancy tracking
       - Return instance index if successful, -1 if failed
  </action>
  <verify>grep -c "computeBuildingDemand\|autoConstructBuilding\|findBuildingPlacement" src/simulation/growth-system.ts</verify>
  <done>Growth system includes construction demand detection and building placement logic</done>
</task>
