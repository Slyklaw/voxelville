       - size: [number, number, number] (width, height, depth in voxels)

       - Adults (male/female): 3 voxels wide × 4 voxels tall × 1 deep (~18 voxels)
       - Children: 3 voxels wide × 3 voxels tall × 1 deep (~12 voxels)

    4. Each variant should have:
       - Different hair color (black, brown, blond, red)
       - Different clothing color (blue, green, orange, purple, pink)
       - Same base structure (head, torso, 2 arms, 2 legs)

    Reference research document `.planning/phases/02-characters/02-RESEARCH.md` §1.3 for exact voxel layout example.

       - Import `InstancedPool` from `./instancing`
       - Import `getMaterial` from `./materials`
       - Import `getVoxelGeometry` from `./voxel-mesh`
       - For each model variant, create an InstancedPool with:

         - maxInstances: 50 (per variant, 900 total capacity)
       - Add each pool's mesh to the scene

    3. Public methods:
       - `addCharacter(modelId: string, position: THREE.Vector3): number`
         - Finds pool by modelId, calls pool.addInstance(position), returns instance index
       - `updateCharacter(modelId: string, index: number, position: THREE.Vector3): void`
         - Finds pool by modelId, calls pool.updateInstance(index, position)
       - `clear(): void`
         - Clears all pools
       - `dispose(): void`
         - Disposes all pools

    4. Internal state:
       - `pools: Map<string, InstancedPool>` — maps modelId to pool
       - `instanceIndices: Map<string, Map<number, number>>` — maps modelId → (instanceIndex → count)

    Follow existing patterns from `src/engine/instancing.ts` for InstancedPool usage.
  </action>
