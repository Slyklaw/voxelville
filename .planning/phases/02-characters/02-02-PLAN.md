<task type="auto">
  <name>Task 1: Create simulation/render state separation interfaces</name>
  <files>src/simulation/character-state.ts</files>
  <action>
    Create new file `src/simulation/character-state.ts` with:

    1. `AnimationState` type:
       - `'idle' | 'walk' | 'work' | 'party' | 'clean' | 'sleep' | 'build'`

    2. `CharacterSimState` interface (updated by simulation at 4 ticks/sec):
       - `position: THREE.Vector3` — current grid position (integer coordinates)
       - `targetPosition: THREE.Vector3` — next grid position (for pathfinding)
       - `animationState: AnimationState` — current animation state
       - `previousPosition: THREE.Vector3` — position before last tick (for interpolation)
       - `previousAnimation: AnimationState` — animation before last tick
       - `tickTimestamp: number` — performance.now() of last simulation tick
       - `modelId: string` — character variant (e.g., 'male_1')
       - `instanceIndex: number` — index in InstancedPool

    3. `CharacterRenderState` interface (updated every frame at 60fps):
       - `interpolatedPosition: THREE.Vector3` — computed position for this frame
       - `interpolatedRotation: number` — facing direction (Y-axis rotation)
       - `animationOffset: THREE.Vector3` — animation transform (Y-bob, etc.)
       - `animationPhase: number` — animation cycle position (0..1)

    4. `interpolateCharacter()` function:
       - Parameters: sim: CharacterSimState, render: CharacterRenderState, currentTime: number
       - Compute alpha = min((currentTime - sim.tickTimestamp) / 250, 1.0) // 250ms = 4 ticks/sec
       - Lerp render.interpolatedPosition between sim.previousPosition and sim.position
       - Compute render.animationPhase based on sim.animationState and alpha

    Import THREE from 'three'.
  </action>
  <verify>npx tsc --noEmit src/simulation/character-state.ts</verify>
  <done>Simulation/render state interfaces defined with interpolation function</done>
</task>
